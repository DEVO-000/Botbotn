# DEVO+WORKS — обновление бота (полный список изменений)

Обновлённый `main.py` — 100% совместим со старыми данными (users.json, classes.json,
prices.json и т. д.). Все старые функции, кнопки и команды сохранены.

## 1. ⚡ Автоматизация через DeepSeek API (НОВОЕ)

Бот понимает обычные фразы и сам выполняет действия:

- «**русский на пятницу этой недели страница 45**» → бот создаст ДЗ на пятницу;
- «**замени учителя по биологии, географии и обществознанию на Иванову**» → заменит учителей сразу по трём предметам;
- «добавь дз по алгебре на завтра №120-125», «удали дз по химии на завтра»;
- «поставь таймер на завтра 14:30 — встреча», «покажи домашку на завтра», «погода», «какие звонки?» и т. д.

**Как включить:** кнопка «⚡ Автоматизация» в главном меню или команда `/auto` (`/авто`).
Повторный `/авто` или кнопка «❌ Выйти из режима» — выход.

**Как это устроено (честно и продуманно):**
- фраза уходит в **DeepSeek API** (`deepseek-chat`), который возвращает строгий JSON-намерение;
- **изменяющие** действия (добавить/удалить ДЗ, заменить учителя, звонки, расписание, таймер)
  сначала показываются на **подтверждение** (кнопки «✅ Выполнить» / «❌ Отмена») — бот ничего не меняет молча;
- действия просмотра выполняются сразу;
- писать может только админ класса (или разработчик) — ученикам доступны просмотры и таймеры;
- названия предметов сопоставляются нечётко: «биологии» → «Биология», «русский» → «Русский язык»;
- режим работает как «оверлей» — доступен в любом состоянии бота и не ломает текущие диалоги;
- если `DEEPSEEK_API_KEY` не задан, а Groq-ключ есть — автоматика временно работает через Groq
  (в лог пишется предупреждение), чтобы функция не «умирала» молча.

**Переменные окружения:**
```
DEEPSEEK_API_KEY=sk-...        # ключ с https://platform.deepseek.com
DEEPSEEK_MODEL=deepseek-chat   # модель (deepseek-chat / deepseek-reasoner)
AUTOMATION_PROVIDER=deepseek   # deepseek (по умолчанию) или groq
```

Поддерживаемые действия: add_homework, delete_homework, replace_teacher (несколько
предметов сразу), add_subject, set_bell, set_schedule, add_timer, show_homework,
show_schedule, show_teachers, show_bells, show_weather, show_today, show_tomorrow.

## 2. Платные кнопки — кастомные товары (НОВОЕ)

- При создании **классной** кнопки (админ-панель → Кнопки) и **глобальной** кнопки
  (панель разработчика) бот теперь спрашивает **цену в звёздах** (0/«бесплатно» — обычная кнопка, как раньше).
- Нажатие платной кнопки → экран товара с ценой → оплата **с внутреннего баланса** ⭐
  или **Telegram Stars (XTR)** → содержимое (текст/ссылка) **доставляется мгновенно**.
- Чек создаётся **динамически под любую сумму** (1–2500 ⭐).
- PreCheckout **проверяет** товар и актуальную цену (если цену изменили — платёж отклонится).
- Админы класса и разработчик видят содержимое своих товаров бесплатно.
- Все кнопки, созданные раньше, остались бесплатными (цена 0 по умолчанию).

## 3. Динамические чеки покупки звёзд (НОВОЕ)

- В меню «⭐ Звезды» → «Купить звёзды» появилась кнопка **«📐 Своя сумма»**:
  вводите любое число 1–2500 — бот создаёт чек XTR ровно на эту сумму.
- PreCheckout валидирует сумму чека (защита от кривых платёжек).

## 4. Синхронизация цен (УЛУЧШЕНО)

- Единый источник цен — `prices.json` (словарь `PRICES`), который читают **все** модули.
- Изменение цены в панели разработчика («⚡ Быстрое изменение цен») применяется
  **мгновенно во всём боте** — без перезапуска.
- Добавлена цена **«🤖 Генерация DEVO+ai»** (`ai_generation`): по умолчанию **0 — бесплатно**
  (прежнее поведение). Если задать цену N, каждое сообщение к DEVO+ai стоит N внутренних ⭐:
  при нехватке баланса бот предложит купить звёзды; списание — только после успешного ответа модели.
- В панель быстрых цен добавлены подписи для всех ключей (в т. ч. «Место под анонимки», «Генерация DEVO+ai»).
- Инструкция (v2.3) автоматически обновится и показывает актуальные цены, включая новые.

## 5. Статистика Stars (ПЕРЕРАБОТАНО)

- **Подробная история переводов полностью удалена** (старый список `transactions` вычищается
  из файла при первом запуске и больше никогда не пишется).
- «📊 Статистика звёзд» показывает только:
  - 👥 общее число пользователей;
  - 💸 суммарно потраченные звёзды (внутренние + Telegram Stars);
  - 🏆 топ-10 пользователей по тратам.
- Все оплаты XTR (кнопки, разблокировки, отправители, место под анонимки, товары)
  теперь честно учитываются в тратах через единую функцию `record_stars_purchase`.

## 6. Исправление: погода

- **Ежедневная рассылка погоды снова работает**: приходит раз в день в
  `user.weather_notification_time` по **локальному времени** пользователя.
- **Часовой пояс**: определение с точностью до четверти часа — поддерживаются
  зоны вида UTC+5:30 (раньше округлялось до целого и сдвигало время);
  парсинг старых значений («+3», «UTC+3») сохранён.
- **Задачи рассылки хранятся в БД**: расписание — в `users.json`, журнал отправок —
  в `notification_log.json`. Перезапуск бота не теряет рассылки: тикер дочитает
  расписание из БД, а «окно догона» доставит пропущенное уведомление.
- Защита от долбёжки WeatherAPI — не чаще одной попытки на пользователя раз в 15 минут.
- Экран «🌦 Настройки погоды» теперь показывает реальное состояние (вкл/выкл, время, город, пояс).

## 7. Исправление: бесконечный цикл звонков

- **Причина бага:** обработчик времени окончания звонка существовал, но не был
  зарегистрирован в машине состояний — после ввода «времени начала» бот снова
  просил начало, и так до бесконечности.
- **Исправление:** добавлено состояние `EDIT_BELL_END` с чётким переходом
  «ввод начала → ввод окончания → сохранение». Ошибка формата времени окончания
  теперь повторно спрашивает именно окончание.

## 8. Быстрые команды — работают везде (НОВОЕ)

Зарегистрированы ВЫШЕ основной FSM, поэтому срабатывают в любом состоянии бота
(во время ввода ДЗ, в админке, в чате с AI…) и не ломают текущие шаги:

| Команда | Действие |
|---|---|
| `/dz` `/дз` `/homework` `[дата]` | ДЗ: всё или на дату («завтра», 2025-09-15, 15.09) |
| `/today` `/сегодня` | расписание и ДЗ на сегодня |
| `/tomorrow` `/завтра` | расписание и ДЗ на завтра |
| `/schedule` `/расписание` | расписание на неделю |
| `/teachers` `/учителя` | список учителей |
| `/bells` `/звонки` | звонки |
| `/weather` `/погода` | погода сейчас (+ прогноз на 3 дня) |
| `/timer` `/таймер` | быстрый таймер |
| `/stars` `/звезды` | меню звёзд |
| `/auto` `/авто` | режим автоматизации |

Команды уважают все проверки: подписка на канал, блокировки, регистрация.
`/start`, `/restore`, `/cancel` работают как раньше — быстрые команды их не перехватывают.

## Запуск

```
pip install -r requirements.txt   # новые зависимости не нужны (DeepSeek — через aiohttp)
```

Переменные окружения: `BOT_TOKEN`, `GROQ_API_KEY`, `DEVELOPER_ID` (как раньше) +
опционально `DEEPSEEK_API_KEY`, `DEEPSEEK_MODEL`, `AUTOMATION_PROVIDER`.

> Примечание об «внешних платёжных системах»: по правилам Telegram Bot Payments
> цифровые товары и услуги внутри чатов с ботами продаются за Telegram Stars (XTR),
> поэтому все чеки в боте — Stars. Это единственный легальный способ для цифровых услуг.
