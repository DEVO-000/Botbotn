# 🌐 DEVO+ Облако (Mini App) — подключение и деплой

ВОЛНА 22.21. Главное отличие от прошлой версии: мини-апп теперь — **часть
самого бота**. Отдельный Node/Next.js-хостинг больше НЕ нужен. Бот раздаёт
HTML и JSON API из того же процесса, а список файлов берёт из ОСНОВНОЙ базы
бота (users.json → cloud_files): загрузили через веб — файл виден в чате
(☁️ Облако), и наоборот. Хранилище — тот же приватный канал (или СВОЙ личный
канал из «🔗 Моё облако»).

## Что где лежит (в архиве school-bot-updated.zip)

```
main.py                  — бот + веб-API мини-аппа (/ и /api/*)
miniapp/index.html       — приложение «DEVO+ Облако» (дизайн не менялся)
MINIAPP_DEPLOY.md        — этот файл
requirements.txt         — зависимости (aiohttp уже нужен боту)
ЧТО_НОВОГО.md            — история изменений
```

## Как это работает

| Маршрут | Назначение |
|---|---|
| `GET /`, `GET /miniapp` | HTML приложения (дизайн пользователя) |
| `GET /health` | keep-alive (для Render/Railway и self-ping бота) |
| `GET /api/files` | список файлов из основной базы |
| `PATCH /api/files/{id}` | переименование / галочка Vault |
| `DELETE /api/files/{id}` | удалить (+ сообщение из канала) |
| `GET /api/files/{id}/download` | оригинал байт-в-байт (Bot API ≤20 МБ, дальше MTProto до 2 ГБ) |
| `POST /api/upload/init|chunk|complete|abort` | чанковая загрузка (куски по 4 МБ, честный прогресс, пауза/отмена) |

Загрузка уходит в канал **как документ** — без сжатия: фото и видео не
портятся (ответ на «съедает качество»). Файлы до 49 МБ — через Bot API,
больше — через MTProto/Telethon (до 2 ГБ, `telethon` уже в requirements.txt).

Авторизация: Telegram `initData` (HMAC-SHA256 по официальной схеме, 24 ч) в
заголовке `X-Telegram-Init-Data`. Открыть API извне без подписи Telegram
нельзя. Пользуется облаком только зарегистрированный пользователь бота.
Панели разработчика в приложении НЕТ — у каждого пользователя свои файлы и
своя настройка канала в боте («🔗 Моё облако»).

## Шаги подключения

1. **Разверните бота** (zip → распаковать → `pip install -r requirements.txt`
   → `BOT_TOKEN=... python main.py`). Веб-сервер стартует сам на порту
   `PORT` (по умолчанию **8080**) — это обычный HTTP-сервер aiohttp.

2. **Дайте ему публичный HTTPS-адрес** (Telegram Mini App работает только
   по HTTPS). Любой из вариантов:
   - **VPS + Caddy** (проще всего): домен `cloud.example.com` → A-запись на
     VPS, в Caddyfile две строки —
     `cloud.example.com { reverse_proxy 127.0.0.1:8080 }` — сертификат
     Caddy получит сам;
   - **nginx**: `proxy_pass http://127.0.0.1:8080;` (+ certbot для
     сертификата);
   - **Render/Railway**: бот и так слушает `PORT` платформы — публичный
     URL сервиса уже HTTPS, ничего дополнительно не нужно;
   - **быстрый тест**: `cloudflared tunnel --url http://localhost:8080`
     или ngrok.

3. **Пропишите адрес боту**: переменная окружения
   ```
   MINIAPP_URL=https://cloud.example.com
   ```
   При старте бот один раз поставит кнопку меню «☁️ DEVO+» (MenuButtonWebApp)
   и покажет кнопку «🌐 Веб-облако (Mini App)» в меню ☁️ Облако — это те самые
   точки входа. Если MINIAPP_URL не задан, кнопки не появляются, а сам адрес
   приложения просто открывается в браузере по вашему HTTPS-URL.

4. **Готово.** Откройте бот → кнопка меню «☁️ DEVO+» (или ☁️ Облако →
   🌐 Веб-облако) — файлы в вебе и в чате одни и те же.

## Честные ограничения

- Telegram требует HTTPS — «просто открыть http://ip:8080» в Telegram нельзя.
- Файлы **>2 ГБ** не пропускает ни один бот Telegram (это потолок Telegram,
  не бота); >49 МБ нужен установленный Telethon (есть в requirements.txt).
- Скачивание через веб: ≤20 МБ — Bot API, больше — MTProto; если Telethon
  недоступен, API честно ответит 503 и подскажет скачать через чат.
- Галочка **Vault** в веб-облаке — отдельная папка просмотра в списке
  (фильтр «🔒»): это НЕ шифрование. Зашифрованный Сейф с паролем — только
  через чат (🔐 Сейф), там zero-knowledge шифрование AES-256.
- Временные файлы загрузки лежат в `BOT_DATA_DIR/miniapp_uploads/` (или
  рядом с main.py) и стираются после отправки в канал.
- На сервере мини-аппа уже есть BOT_TOKEN (это сам процесс бота) — отдельный
  секрет передавать не нужно.
